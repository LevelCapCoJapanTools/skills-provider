# さくらのクラウド サーバー操作スキル

## provider

sakura

## 認証方法

- 環境変数 `SAKURA_API_TOKEN` / `SAKURA_API_SECRET` を使用する
- さくらのクラウド API エンドポイント: `https://secure.sakura.ad.jp/cloud/zone/<ゾーン>/api/cloud/1.1/`
- ゾーンは環境変数 `SAKURA_ZONE` で指定する
- Credentials はコード・ファイルに直書きしない
- 認証情報は外部（環境変数）で管理する

## 実行条件

- `SAKURA_API_TOKEN` / `SAKURA_API_SECRET` / `SAKURA_ZONE` がすべて設定されていること
- 操作対象のサーバー ID が明示されていること
- API トークンが対象サーバーへの必要権限を保持していること
- 権限は最小限に限定すること（権限過剰禁止）

## 副作用

| 操作 | 副作用 |
| --- | --- |
| 起動（Power ON） | サーバーを起動する。リソース費用が発生する |
| シャットダウン（Power OFF） | サーバーを停止する |
| 強制電源断（Force Power OFF） | サーバーを強制停止する。データ損失のリスクがある |
| 一覧（List Servers） | 副作用なし（読み取り専用） |
| 状態確認（Get Server） | 副作用なし（読み取り専用） |

## 失敗時の挙動

- 認証エラー（401 Unauthorized）: 即時失敗。エラーメッセージを出力して停止する
- サーバー不在（404 Not Found）: 即時失敗。エラーメッセージを出力して停止する
- 操作不可（サーバー状態不正）: 即時失敗。現在の状態を出力して停止する
- ゾーン未設定: 即時失敗。設定不足のエラーメッセージを出力して停止する
- ネットワークエラー: 即時失敗。自動リトライは行わない
- すべての失敗は明示的にエラーとして返す

## 禁止事項

- Credentials のログ出力・コメント・ファイル埋め込みを禁止する
- 自動リトライを禁止する
- サーバーの削除（Delete Server）はこのスキルに含めない
- 汎用ロジックをこのスキルに混入することを禁止する（汎用処理は skills-core へ）
- ドメインロジックをこのスキルに混入することを禁止する（ドメイン処理は skills-domain へ）
